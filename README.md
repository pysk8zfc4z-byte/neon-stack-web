# NEON STACK （ビルド成果物）

夕暮れの街から光るキューブを積み上げ、雲を抜けて宇宙まで登る1タップゲーム。

**遊ぶ: <https://pysk8zfc4z-byte.github.io/neon-stack-web/>**

このリポジトリは公開用のビルド出力だけを置いている。ソースと仕様書は別の非公開リポジトリ。
手で編集しない。`npm run deploy` で丸ごと入れ替わる。

- 個人使用。課金・広告・アカウント・解析なし
- **外部通信を一切しない。**記録はブラウザの localStorage にベスト段数1つだけ
- 画像素材を使わない。すべて Canvas にコードで描いている
- 一度開けばオフラインでも起動する（Service Worker）
